# STRATIVA — صفحهٔ Home

این مخزن، مخزن **عمومی** صفحهٔ معرفی (Landing Page) محصول **STRATIVA** است و توسط GitHub Pages منتشر می‌شود.

🔗 **آدرس سایت:** https://alimogharrebi.github.io/strativa-home/

---

## این صفحه چیست؟

صفحهٔ Home یک صفحهٔ تک‌فایلی، کاملاً فارسی و راست‌به‌چپ است که محصول را معرفی می‌کند و کاربرد بخش‌های مختلف نرم‌افزار را نشان می‌دهد. این صفحه به‌عنوان مقصدِ تبلیغات (مثلاً لینک بیو اینستاگرام) طراحی شده است.

محتوای صفحه:

- معرفی محصول و ارزش پیشنهادی آن
- **۴۳ ماژول داده** در **۱۳ دامنهٔ مدیریتی**، هر ماژول با یک توضیح یک‌خطی از کاربردش
- **۷ روش امتیازدهی** به‌همراه فرمول و استاندارد مرجع هر روش
- **۹ بُعد ارزیابی بلوغ** با وزن‌ها و **نردبان پنج‌سطحی**
- ۱۰ استاندارد مرجع (BSC، Strategy Map، OKR، Hoshin Kanri، EFQM، ISO 31000، COSO، ISO 9001، ISO 30414، PMI) و اینکه هر کدام در کدام ماژول سامانه پیاده شده است
- چرخهٔ مدیریت استراتژیک، زنجیرهٔ تجمیع امتیاز، نماهای تخصصی و پرسش‌های متداول

## منبع اصلی (Source of truth)

⚠️ این مخزن **تولیدشده** است. فایل‌های نهایی اینجا قرار می‌گیرند، اما منبع اصلی صفحه در مخزن خصوصی برنامه قرار دارد:

```
C:\projects\docs\
├── index.html                  ← ساختار صفحه
├── LANDING-README.md           ← همین فایل راهنما (به README.md تبدیل می‌شود)
└── assets\
    ├── landing.css             ← استایل‌ها و ریسپانسیو
    ├── landing.js              ← محتوا و تعامل‌ها (بدون وابستگی)
    ├── favicon.svg
    └── fonts\Vazirmatn-var.woff2   ← فونت وزیرمتن (SIL OFL 1.1)
```

## به‌روزرسانی سایت

پس از هر تغییر در `docs\` (در مخزن برنامه)، این دستور را اجرا کنید:

```powershell
cd C:\projects
powershell -File scripts\publish-landing.ps1
```

اسکریپت به‌صورت خودکار فایل‌ها را به این مخزن کپی، commit و push می‌کند و GitHub Pages چند لحظه بعد به‌روز می‌شود.

## ویژگی‌های فنی

- **بدون وابستگی خارجی:** فونت به‌صورت محلی میزبانی می‌شود؛ هیچ CDN یا اسکریپت ثالثی بارگذاری نمی‌شود.
- **بدون مرحلهٔ Build:** فایل‌های استاتیک خالص؛ کافی است push شوند.
- **دسترس‌پذیری (a11y):** ساختار عنوان‌ها، `aria` مناسب، پشتیبانی از `prefers-reduced-motion`، کنتراست رنگی و امکان پیمایش با کیبورد.
- **ریسپانسیو:** طراحی برای موبایل، تبلت و دسکتاپ.
- **SEO:** توضیحات متا، تگ‌های Open Graph و داده‌های ساختاریافتهٔ JSON-LD.

## مجوز

محتوای متنی و برند STRATIVA متعلق به صاحب محصول است. فونت وزیرمتن تحت مجوز SIL Open Font License 1.1 منتشر شده است (فایل `assets/fonts/OFL.txt`).
